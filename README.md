# TOUCHLINE / 边线足球

一个以老版实况的直接操作感为目标的桌面浏览器足球原型。5 对 5（每队含门将），操控翡翠联向右进攻，AI 操控珊瑚竞技。每场实际比赛时间 3 分钟，比赛时钟从 00:00 走到 90:00；进球和死球重开时短暂停表。

## 运行

直接双击 `index.html`，使用 Chrome、Edge、Safari 或 Firefox 打开即可，完全离线可玩。没有依赖、CDN、外部字体或素材。

也可以在此目录运行：

```sh
npm start
```

打开 http://127.0.0.1:8765 。需要 Python 3。若端口被占用，可用 `python3 -m http.server 8766 --bind 127.0.0.1`。

## 操作

| 按键 | 功能 |
| --- | --- |
| 方向键 / WASD | 八方向移动；带球时调整传球朝向 |
| Shift | 冲刺，消耗体力；松开后恢复 |
| J | 有球短传，无球抢断 |
| L | 向队友前方直塞 |
| 按住 K，松开 | 蓄力射门；方向键上/下影响瞄准，向后则向后踢 |
| 空格 | 切换靠近足球的场上球员 |
| Esc | 暂停 / 继续 |

短传优先选择朝向内的队友，传出后自动切换到接球队员。AI 控制其余队友与门将。切换窗口或浏览器标签会自动暂停。

## 已实现

- 120 Hz 固定步长模拟；带惯性和体力的移动；带球、地面传球、直塞、蓄力射门。
- 基础接应、压迫、抢断、门将拦截；休闲与标准两种对手速度。
- 进球判定、比分、界外球、角球、球门球自动重开；暂停、重新开赛、全屏、可选合成音效。
- 球场与人物由 Canvas 程序绘制，小地图展示全场位置。

这是验证手感的 2D 俯视原型，还没有 3D 骨骼动画、越位/犯规/点球、换边、联网和手柄支持。死球使用简化的自动摆球重开。强度选项目前调整对手移动速度。未使用实况足球的代码或游戏素材。

## 开发

`engine.js` 是无 DOM 的模拟核心；`game.js` 负责渲染、输入、音效和界面。没有构建步骤。

```sh
npm run check
npm test
```

浏览器控制台可用 `touchline.match` 检查比赛状态。运动与 AI 参数在 `engine.js` 的 `move`、`ai` 中，传球与射门在 `pass`、`shoot` 中。
